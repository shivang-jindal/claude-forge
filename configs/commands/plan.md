# /plan

Produce an implementation plan for the given task.

1. Restate the goal in one sentence and list explicit non-goals.
2. Break the work into ordered steps; mark dependencies and which can run in parallel.
3. Call out risks/unknowns and how you'll verify each step.
4. Name the files/functions you expect to touch.

Prefer the smallest plan that ships the goal. Do not write implementation code yet.
